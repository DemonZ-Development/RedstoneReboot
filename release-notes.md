## RedstoneReboot 1.6.4

A seasonal patch release for RedstoneReboot.

### Highlights

- A secret Halloween Easter egg was added.
- Bundled dedicated Minecraft 26.x mod builds for all loaders directly into release assets.
- Fixed version range dependency on modern 26.x mod ports to properly allow minor patch releases (e.g. 26.1.x).

### Requirements

- Bukkit, Paper, Spigot, and Purpur: Java 17+
- Folia: Java 17+
- Fabric 1.20.1: Java 17+ (Fabric 26.x: Java 25)
- Forge 1.20.4: Java 17+ (Forge 26.x: Java 25)
- NeoForge 1.21.1: Java 21+ (NeoForge 26.x: Java 25)
